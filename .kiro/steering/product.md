# Product Overview

## Browser Action Game

A client-side browser-based action game where players control characters through 20 progressively difficult rounds, fighting enemies with customizable weapons and stats.

## Core Gameplay

- **Character Selection**: Choose from 3 character types (Warrior, Rogue, Mage) with distinct base stats
- **Combat System**: Real-time top-down combat with up to 6 equipped weapons simultaneously
- **Progression**: Earn currency and stat points after each round to purchase weapons, items, and upgrade attributes
- **Challenge**: 20 rounds with increasing enemy count and difficulty
- **Permadeath**: Failure resets progress to round 1

## Key Features

- 20 unique weapon types with different damage, speed, and range characteristics
- 10 item types providing stat bonuses with strategic trade-offs (penalties)
- Progressive difficulty scaling based on round number
- 5 distinct enemy types with varying stats
- Between-round shop system for purchasing weapons and items
- Stat allocation system for character customization
- Session-based persistence (resets on page refresh)

## Target Platform

Modern web browsers (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+) with no backend requirements.
